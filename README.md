## Course overview

This course introduces modern data ecosystems, relational databases and algorithmic thinking in the context of startups and integrated innovation. Students use cloud-ready spreadsheets, PostgreSQL and Python to collect, structure, clean, analyze and visualize market and product data. The course emphasizes evidence-based entrepreneurial decisions, reproducible workflows, data quality, governance and responsible AI use.

Throughout the semester, weekly labs build toward an integrated startup data pipeline, from defining a business metric and designing a schema to extracting data, validating results and communicating a recommendation.

## Course learning outcomes (CLOs)

By the end of the course, students should be able to:

1. Explain how batch data and product events flow from source to decision, and identify the purpose of a governance control.
2. Structure spreadsheet tables and design relational schemas with a defined row grain, keys and integrity checks.
3. Extract and validate data with PostgreSQL filters, aggregates and joins, and import CSV and public API JSON into a notebook.
4. Express a business rule as a flowchart or pseudocode, implement it in Python, and test ordinary and boundary cases.
5. Clean and summarize data in Python, visualize a product metric or trend, and explain its implications and limitations.
6. Build and defend a reproducible startup data pipeline with documented sources, quality checks, a chart and a recommendation.

## Responsible AI and academic integrity

- Use AI only when permitted, for activities such as brainstorming, language feedback, code explanation or debugging.
- Use synthetic or approved public data; never upload personal or confidential data, credentials or assessment materials to external AI tools.
- Verify AI suggestions against documentation, course data and known results, including boundary cases.
- Write your own interpretations, conclusions and recommendations, and disclose permitted AI use.
- For AI-assisted code, include an **Understanding Log** describing the tool, assistance received, code logic, verification or corrections, and how the code could be adapted to another business question.
- AI is prohibited during quizzes, skill checks and examinations unless explicitly authorized for that activity.

Attendance, active participation, timely submission and academic integrity are expected. Follow the official course instructions on MyCourseVille.
